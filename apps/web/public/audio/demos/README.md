# Демонстрационные звонки

Сценарии и постоянные voice_id: `lib/demo-scenarios.json`.
Готовые файлы: `auto-service-ru.mp3`, `clinic-ru.mp3`.
Манифест с измеренными таймкодами: `lib/demo-audio.generated.json`.

Сейчас манифест пуст: бесплатная очередь ElevenLabs выполнила только 9 из 17
реплик. Бесплатный тариф пользователя не включает коммерческую лицензию.
Фрагменты не публикуются; интерфейс честно показывает отсутствие аудио.

Для завершения заново сгенерировать **все** реплики на платном тарифе ElevenLabs
(переход на платный тариф не лицензирует старые бесплатные генерации).
Сохранять по одной реплике в `<source>/<scenario-id>/00.mp3`, `01.mp3`, …,
с постоянным voice_id участника. Использовать официальный API/SDK с ключом
из защищённого окружения либо подключённый коннектор. Не добавлять ключ в Git.
Проверить произношение, различимость голосов и дословное совпадение со сценарием.

После подтверждения лицензии и прослушивания, из `apps/web`:

```sh
python3 scripts/assemble-demo-audio.py /path/to/paid-recordings --reviewed --commercial-license
pnpm build
E2E_URL=http://localhost:3000 pnpm exec playwright test audio.spec.ts
```

Перед E2E запустить production-сервер (`pnpm start`). Скрипт требует ffmpeg/ffprobe,
отказывается собирать неполный разговор, измеряет границы из PCM и добавляет паузы
280 мс. Он ничего не генерирует и не расходует кредиты ElevenLabs. После сборки
проверить итоговые MP3 на слух. `assembledAt` означает момент сборки; происхождение
исходных генераций хранить отдельно с датой и тарифом на момент генерации.

[Коммерческие права](https://elevenlabs.io/docs/overview/administration/billing)
и [Text to Dialogue](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/text-to-dialogue).
Статические симуляции не вызывают LLM, не создают CRM-заявки и не бронируют время.
