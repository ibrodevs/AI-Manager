# Демонстрационные звонки

На сайте опубликованы два готовых MP3, предоставленных пользователем для размещения:

| Файл | Длительность | Размер |
| --- | --- | --- |
| auto-service-ru.mp3 | 44,591 с | 730 393 байта |
| clinic-ru.mp3 | 38,269 с | 629 247 байт |

Оба файла скопированы без перекодирования. Это полные пользовательские записи,
а не незавершённые фрагменты предыдущей генерации. Пути постоянные, локальные
для сайта; воспроизведение не обращается к ElevenLabs.

`lib/demo-audio.generated.json` хранит SHA-256 каждого файла, длительность,
полную расшифровку и границы реплик из распознавания слов ElevenLabs Scribe.
В нём указан источник `user-provided`; модель генерации, voice_id и тариф
аккаунта для этих внешних файлов неизвестны и не выдаются за проверенные.
`lib/demo-scenarios.json` хранит исходные сценарии и имена участников.
В плеере отображается расшифровка фактической записи.

Проверка после замены файла: пересчитать SHA-256, получить новые таймкоды,
обновить манифест и запустить тесты против production-сборки:

```sh
pnpm test
pnpm build
pnpm start
# В отдельном терминале:
E2E_URL=http://localhost:3000 pnpm exec playwright test audio.spec.ts
```

Для сборки новых записей из отдельных лицензированных и проверенных реплик
остаётся `scripts/assemble-demo-audio.py`; текущие готовые MP3 через него
не пропускались. Статические симуляции не вызывают LLM, не создают CRM-заявки
и не подтверждают запись в календарь.
