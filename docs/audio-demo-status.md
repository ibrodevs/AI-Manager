# Публичные аудиодемо: состояние на 7 ноября 2026

## Что исправлено

Плеер больше не симулирует звук таймером. Позиция, длительность, Play/Pause,
перемотка, скорость и окончание следуют HTMLAudioElement. Ошибки загрузки и
запуска отображаются; второй плеер останавливает первый. Обработчики и источник
освобождаются при размонтировании. Существующий API компонентов сохранён.

Карточки показывают сценарии AutoCity Service и клиники «Здоровье», различают
участников цветом и отделяют статические симуляции от интерактивного браузерного
демо. Последнее работает на локальном движке, без LLM и записи в CRM — это
прямо указано в интерфейсе. Удалена неработающая телефонная ссылка; уточнены
маркетинговые обещания. Цена замены масла 1500 сом/30 минут соответствует
`apps/web/scripts/provision-demo.ts`.

## Обязательный незавершённый шаг

**Два полных коммерчески лицензированных MP3 не готовы.** Пользователь подтвердил
бесплатный тариф ElevenLabs. Коннектор сгенерировал 9 из 17 отдельных реплик;
остальные не запустились из-за занятой бесплатной очереди. Повторных попыток
после сообщения об ограничении не было. ELEVENLABS_API_KEY в окружении отсутствует.

Успешные фрагменты сохранены вне Git и public. В репозитории нет их временных URL,
ключей или аудио с бесплатной лицензией. Пустой `demo-audio.generated.json`
означает честный статус «Аудиозапись недоступна», а не готовые аудиодемо.

Для завершения нужны платный тариф и **новая генерация всех реплик на нём**,
проверка на слух, сборка и запуск проверок полных записей. Инструкции и скрипт:
`apps/web/public/audio/demos/README.md`, `apps/web/scripts/assemble-demo-audio.py`.
